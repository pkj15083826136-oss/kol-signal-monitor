# 钱包与手动交易升级基线

本文件记录项目所有者于 2026-09-19 批准的独立范围。它允许分阶段实现钱包连接、只读报价和用户逐笔确认的手动交易，但不改变监控系统的核心职责。

## 不可突破的边界

- 网页、服务端、D1、日志和环境变量均不得接收或保存私钥、助记词或未加密签名材料。
- 服务端不得代签；每笔授权和交易均由当前连接的钱包明确确认。
- 不做自动交易、托管、无人值守签名或默认无限 ERC-20 授权。
- 主网广播默认关闭，必须经过测试网/模拟和逐链小额验收后，由项目所有者单独开启。
- 交易能力必须使用默认关闭的 Feature Flag 分阶段开放；某条链失败不得影响其他链。
- 保持四链、6/18/38/58 信号规则、AI 分析、D1、Sites project_id、公开访问范围和企业微信链路不变。

## 目标架构

- 连接层：Reown AppKit；EVM 使用 Wagmi 2 + Viem，Solana 使用 Reown Solana Adapter。
- 报价层：Solana 优先 Jupiter；BSC、Base、Robinhood Chain 优先 0x Swap API v2。
- 服务端只负责保护 API key、请求校验、报价标准化、限流和 allowlist 校验。
- 前端展示交易摘要，钱包负责签名和广播；卖出余额与 decimals 必须读取链上真实值。
- EVM approval 与 swap 分步展示，默认精确额度授权。
- 金额使用最小单位字符串或高精度 decimal，禁止用 JavaScript 浮点数参与交易计算。
- 第一版不建立用户账户；若以后需要鉴权，只允许一次性 nonce + SIWX/SIWE。

## 分阶段开放

1. Phase 0：冻结生产基线，完成代码/依赖/数据库/部署审计、测试缺口、架构、布局和验收清单。
2. Phase 1：只读钱包连接、切链、余额和断开；无报价、无授权、无广播。
3. Phase 2：3 秒批量行情（隐藏标签页 15 秒）、延迟提示、Lightweight Charts 5m/15m。
4. Phase 3：只读报价、滑点、价格影响、费用、路由和风险提示；禁止广播。
5. Phase 4：测试网/模拟后逐链开启主网小额手动交易、状态跟踪和用户交易记录。
6. Phase 5：可靠性、缓存/降级、健康度、失败率和延迟告警。

任何阶段完成后都必须运行适用测试、lint、构建和生产回归检查，并提交验证结果；未通过不得进入下一阶段。
